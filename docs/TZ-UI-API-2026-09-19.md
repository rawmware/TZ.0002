# TZ Desktop UI — API and Module Contract — 2026-09-19

This is the contract the 2026-09-19 build was split against. Four pieces were built in parallel
(bug fixes in `direct()`/tools, the shared command layer, the UI server, the front end) and this
file is what kept them compatible. Keep it current when any of these interfaces change.

Repo root is `ROOT` (`app/tz_agent.py` `ROOT`). Front-end files live in `ROOT/ui/`. Tracked UI
defaults live in `ROOT/config/ui.defaults.json`; Roman's per-machine overrides live in the
gitignored `ROOT/config/tz.local.json` under a top-level `"ui"` key.

---

## 1. Agent additions (`app/tz_agent.py`)

```python
class Agent:
    default_model: str          # the configured task model at start-up (tz-agent:latest); /auto restores task_model to this
    lock: threading.Lock        # held only while command() runs; turn() itself is NOT locked (workers call turn())
    desktop: object | None      # the app.tz_ui.Desktop instance while the UI is open, else None
    terminal: object | None     # the Terminal when interactive, else None

    def command(self, text) -> dict
        # Shared entry point for the terminal AND the desktop. Handles every slash command that used to
        # live in main(): /help /tools /status /specs /hardware /verbose /clear /models [filter] /use MODEL
        # /auto /fast /code /ui [close|always|never|ask] /sessions, then falls through to self.turn(text).
        # Raises RuntimeError('TZ is busy with another request.') if the lock is already held.
        # Raises ValueError('Unknown command. Use /help.') for unknown slash commands.
        # /exit and /quit are NOT handled here (the terminal loop owns them).
    def sessions(self) -> list[dict]
        # [{'id': str, 'started': float (epoch, from file mtime or id), 'title': str (first user message[:60] or '(empty)'),
        #   'turns': int (count of user messages), 'current': bool}], newest first, read from self.state/*.json.
    def session(self, session_id) -> dict
        # {'id': str, 'messages': [...]} for a saved session; ValueError on a bad id. 'current' is an alias for self.id.
    def resume(self, session_id) -> dict
        # Loads data/tz/<id>.json into self (messages, model, task_model, routing, opencode_session, last_backend), sets self.id.
        # Returns {'id': id, 'turns': n}. ValueError on a bad/missing id. main(--resume) uses this.
    def new_session(self) -> dict
        # Saves the current session, clears messages/pending state, assigns a fresh id. Returns {'id': new_id}.
    def open_desktop(self) -> dict
        # Creates self.desktop = app.tz_ui.Desktop(self, self.terminal) if needed, calls .open(), emits the URL.
        # Returns {'url': url}. If app.tz_ui cannot be imported, raises ValueError('Desktop UI is not available.').
    def close_desktop(self) -> dict
```

`Agent.__init__` gains `self.default_model = self.model`, `self.lock = threading.Lock()`, `self.desktop = None`.

`Agent.emit` stays a plain callable `(value='', end='\n', flush=False)`. The Desktop wraps it to fan out to
browser clients and restores the original on close.

## 2. Terminal additions (`app/tz_terminal.py`)

```python
class Terminal:
    def yes_no(self, question, default=False) -> bool
        # Prints "<question> (Y/N)  [Enter = N]" and reads one line. Accepts y/yes/n/no (any case); empty → default.
        # When not self.enabled (no TTY, tests, --prompt) returns default WITHOUT prompting.
    lock: threading.RLock      # emit()/print_line() are serialized so a UI worker thread can print safely
class Hardware:
    def vram_total(self) -> int | None   # bytes of GPU0 VRAM via nvidia-smi, cached; None when no NVIDIA GPU
```

`Terminal.read()` wraps the prompt in `prompt_toolkit.patch_stdout.patch_stdout(raw=True)` so lines emitted by a
background (UI) turn appear above the input box instead of corrupting it.

## 3. New tool: `local_time`

```
local_time {'zone': str}  ->  {'zone': 'Asia/Tokyo', 'place': 'japan', 'time': '2026-09-19 03:12:44', 'iso': '...', 'utc_offset': '+09:00', 'note': ...}
```
`zone` accepts either an IANA name or a place from the alias table (`japan`, `tokyo`, `new mexico`, `albuquerque`,
`portsmouth nh`, `new hampshire`, `boston`, `new york`, `nyc`, `london`, `california`, `los angeles`, `la`, `chicago`,
`denver`, `phoenix`, `seattle`, `paris`, `berlin`, `sydney`, `india`, `utc`, `here`/`local`…). Unknown place →
`ValueError('Unknown place: X. Use open_target with a Google search instead.')`. Requires `tzdata` on Windows
(`requirements.txt`).

## 4. UI server (`app/tz_ui.py`)

```python

    # minus ids in 'removed'. Always returns every key with a value.
def write_ui_config(changes: dict, root=ROOT) -> dict
    # Whitelisted keys only: open, wallpaper, wallpaper_image, chime, presets, removed. Anything else → ValueError.
    # Writes ONLY tz.local.json['ui'] (creates the file if missing, preserving passcode/launcher). Returns ui_config().

def set_open_mode(mode, root=ROOT) -> str

    def __init__(self, agent, terminal=None, root=ROOT)
    def open(self) -> str      # starts the loopback server if needed, opens the browser (webbrowser.open) on the token URL, returns it
    def url(self) -> str       # http://127.0.0.1:<port>/<token>/ui/
    def close(self)            # stops the server, restores agent.emit / agent.confirm, sets nothing else on the agent
```

Server: `ThreadingHTTPServer` on `127.0.0.1`, port 0 (random), `daemon_threads = True`. 32-hex token from
`uuid.uuid4().hex`. Every request path must start with `/<token>/`, otherwise 404 with no body hint. Headers on every
response: `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`, and on HTML
`Content-Security-Policy: default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline'; connect-src 'self'`.
JSON bodies are UTF-8; errors are `{"error": "..."}` with 400/404/409/500.

### Endpoints (all under `/<token>/`)

| Method | Path | Request | Response |
|---|---|---|---|
| GET | `ui/` | | `ui/index.html` |
| GET | `ui/<asset>` | | file from `ROOT/ui/` (path-traversal guarded, `mimetypes`) |
| GET | `api/state` | | `{label, model, model_description, task_model, routing, session_id, workspace, busy, specs: [[label, value], ...], readings: str, version: "0.4"}` — `specs` from `terminal.hardware.specs()` when a terminal exists, else `[]`; `readings` from `terminal.hardware.readings` or `""` |
| GET | `api/events` | | SSE stream (`text/event-stream`). See event types below. First event is `hello` with the same body as `api/state`. A `: keep-alive` comment every 15 s. |
| POST | `api/turn` | `{"text": "..."}` | `202 {"accepted": true}` — runs `agent.command(text)` on a worker thread with `agent.confirm` bridged to the UI for the duration. `409 {"error": "busy"}` if the agent lock is held. `400` on empty text. |
| POST | `api/confirm` | `{"id": "...", "answer": true}` | `{"ok": true}`; `404` if no such pending confirm |
| GET | `api/sessions` | | `agent.sessions()` |
| GET | `api/sessions/current` | | `agent.session(agent.id)` → `{id, messages}` |
| GET | `api/sessions/<id>` | | `agent.session(id)` |
| POST | `api/sessions/<id>/resume` | | `agent.resume(id)` → `{id, turns}`; `409` if busy |
| POST | `api/sessions/new` | | `agent.new_session()` → `{id}`; `409` if busy |
| GET | `api/config` | | `ui_config()` |
| PUT | `api/config` | subset of whitelisted keys | `write_ui_config(body)` → merged config; `400` on unknown key |
| GET | `api/models` | | `[{"name": "...", "size": bytes}]` from Ollama `/api/tags`; `[]` when Ollama is down. Also `vram_total` (bytes or null) as `{"models": [...], "vram_total": n}` |
| POST | `api/open` | `{"url": "https://..."}` | `agent.tool('open_target', {'target': url}, explicit=True)`; only `http(s)://` accepted, `400` otherwise |
| GET | `api/files?path=<rel>` | | `{path, entries: [{name, dir: bool, size: int}]}` inside the workspace only; `.` default |
| GET | `api/file?path=<rel>` | | raw bytes with the right `Content-Type` for images (`png/jpg/jpeg/gif/bmp/webp/svg`) and `text/plain; charset=utf-8` for text files under 1 MB; inside the workspace only; `404`/`415` otherwise |

### SSE event types (each `data:` line is one JSON object)

```
{"type": "hello",      ...same as api/state}
{"type": "line",       "text": "<a complete emitted line>"}             # emit(value) with end='\n'
{"type": "stream",     "text": "<partial model token(s)>"}              # emit(piece, end='')
{"type": "turn_start", "text": "<user text>", "source": "ui" | "terminal"}
{"type": "turn_end",   "ok": true | false, "error": "<message if not ok>"}
{"type": "confirm",    "id": "<hex>", "question": "Replace existing file ...?"}
{"type": "confirm_done", "id": "<hex>", "answer": true | false}
{"type": "status",     "readings": "CPU ... | RAM ... | GPU ...", "model": "...", "routing": "auto", "session_id": "...", "busy": false}   # ~1/s
{"type": "session",    "id": "<new current session id>"}               # after resume / new_session
```

The Desktop publishes `turn_start`/`turn_end` for turns from **both** faces by wrapping `agent.command` while the
desktop is open (the wrapper marks `source` per call). A confirm request blocks the worker thread for at most 120 s,
then answers `False`.

## 5. Front end (`ui/`)

Files: `index.html`, `desktop.css`, `desktop.js`, `icons/<name>.svg` (`start`, `chat`, `search`, `browser`, `files`,
`settings`, `clock`, `preset`, `tz`). Plain ES2020, no framework, no CDN, no inline `<script>`. All API calls are
relative to the page (`../api/state` from `/<token>/ui/`). The page must still render the desktop (icons, wallpaper,
clock) when every API call fails, showing a `[offline]` note in the status strip.

Windows (Win 3.1 chrome; minimize-to-icon; positions in `localStorage` under `tz.win.<name>`):
- **Boot** overlay — black, monospace, prints the `specs` rows from `api/state` one per 40 ms, then removes itself (click skips).
- **Start** — greeting, specs table, a text field. Submits via `api/turn`. Opens on first load.
- **Chat** — renders `api/sessions/current` messages, then live events (`line`, `stream`, `turn_start`, `turn_end`).
  `Me >` input + Send. `◀ n/N ▶` session pager backed by `api/sessions`; selecting one calls `api/sessions/<id>/resume`.
  "New" button → `api/sessions/new`.
- **Search** — grid of preset icons from `api/config.presets`; `+ New preset` dialog (Name, Phrase, Mode radio, Icon) saves
  via `PUT api/config {presets: [...]}`; right-click/Delete removes (default presets go into `removed`).
- **Browser** — tiny dialog with a URL/search field; `api/open`. Enter with no scheme → Google search URL.
- **Files** — File Manager look: folder list left, files right, from `api/files`; clicking a text file shows it via `api/file`.
- **Settings** — wallpaper color (`<input type=color>`), wallpaper image (workspace path, preview via `api/file`),
  model `<select>` from `api/models` (submits `/use <name>` through `api/turn`), routing radios (AUTO/MANUAL → `/auto` or
  `/use <task_model>`), "Open UI on start" radios (ask/always/never), startup chime checkbox. Saves via `PUT api/config`.
- **Clock** — always open, local time, updates every second.
- **Confirm** message box for `confirm` events → `POST api/confirm`.
- **Status strip** at the bottom: `model · ROUTING · label  |  readings`, from `status` events.

Palette tokens in `desktop.css`: `--desk #008080`, `--chrome #C0C0C0`, `--title-active #000080`, `--title-inactive #808080`,
`--bevel-light #FFFFFF`, `--bevel-dark #808080`, `--bevel-darker #000000`. Font stack
`"MS Sans Serif", "Microsoft Sans Serif", Tahoma, sans-serif` at 11–12 px.
